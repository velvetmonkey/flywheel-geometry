# Activation steering experiments — daily log

**2026-04-29** — Set up TransformerLens against Gemma 3 12B, residual stream hooks at layer 18 (mid-network). Steered toward "playful" by averaging activations from 50 prompts containing the concept and subtracting a neutral baseline. Got the expected shift in tone. Sanity check passed.

**2026-04-30** — Tried to steer toward "Tuesday." Got incoherent output around the steering coefficient sweep. Direct evidence of the geodesic-vs-linear thing: Tuesday is on a circle (days of week), and pushing along the linear average direction takes you off the circle into the void. Distribution becomes ill-defined. Had to back off the coefficient by 4× to recover coherent output.

**2026-05-01** — Replicated on Llama 3.1 8B with the same prompt set. Same failure mode. Cross-architecture stability of the failure suggests it's a property of the underlying manifold, not the specific model. Logging this as positive evidence the day-of-week ring is a real geometric structure rather than a quirk of one model.

**2026-05-04** — Started writing up a small note for the personal corpus. Realised mid-draft that the "geodesic interpolation stays coherent" claim from the talk needs a more rigorous test than I've done — I've shown linear steering breaks; I haven't shown geodesic steering doesn't. Need to actually fit a geodesic to the day-of-week ring and steer along it. Saved as a Crucible task for next week.

**Pattern**: every steering experiment that doesn't respect existing structure fails predictably. Every one that does respect it works mundanely. The interesting science isn't in the failures — it's in *which structures the model actually maintains internally vs which we project onto it.* That's the difference between manifold cartography and apophenia.
